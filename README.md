# Hop Up

 This game is inspired by the original Doodle Jump game recreated in unity by me. The core concept is the same as og game: you have to keep going up as high as possible, get your high score, and try to beat your high score in the next game.

## How to Play

- Use the **arrow keys or A/D** to change direction.
- Try to get as high as possible.
- Score points as you progress, like in the original Doodle Jump.
- Try to beat your high score!

## Features

- Simple and fun gameplay.
- Endless jumping inspired by Doodle Jump.
- A scoring system inspired by the original game.
- Arrow keys or A/D controls to change direction.
- Made with Godot!

## Built With

- **Unity Engine** — making the game.
- **C#** — for the game's scripts.
